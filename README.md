# Олимпиада по английскому: тренажёр

Тренажёр к муниципальному этапу ВсОШ по английскому языку, 10–11 классы. Задания 2022–2026 по разделам, проверка сразу с правильными ответами и пояснениями.

| Что | Файл |
|---|---|
| Страница тренажёра | `index.html` |
| Задания, ключи и пояснения | `data.js` |
| Аудио к аудированию | `audio/<год>.mp3` |

Письменные работы отправляются учителю через тот же Google Apps Script, что и в пробниках ОГЭ.
